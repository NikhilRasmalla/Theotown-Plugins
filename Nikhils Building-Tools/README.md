# Nikhil’s Building Tools

Lua tools for TheoTown that help you browse buildings, filter by size, and create custom building packs.

## Features

- Browse individual buildings and plugin packs.
- Filter buildings by footprint size.
- Build custom packs from available buildings.
- Keep listings updated when plugins are removed or unavailable.
- View detailed feature explanations and release notes within the tool.

## Installation

1. Download `Nikhils_Building_Tools.lua`.
2. Place it in your TheoTown plugins folder.
3. Restart TheoTown to load the script.

## Usage

Open **Nikhil’s Building Tools** in the game and choose the building selector or pack builder. Open **Release Notes** for detailed instructions and feature explanations.

## Compatibility

Tested in-game on TheoTown Steam. Available buildings depend on the plugins installed and loaded in your game.
